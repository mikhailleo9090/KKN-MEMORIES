# KKN MEMORIES — Siap Dibuka

1. Buka `index.html` dengan Chrome/Edge/Firefox.
2. Website sudah berisi halaman scrapbook KKN, anggota, galeri, timeline, surat, guestbook, countdown, dan music player.
3. Foto asli belum disertakan pada file yang kamu upload, jadi paket ini memakai gambar placeholder yang bisa diganti nanti.
4. Ganti file di `assets/members/` dan `assets/memories/` dengan foto kamu. Jika nama file tetap sama, tidak perlu mengubah JavaScript.
5. Musik juga memakai audio placeholder. Ganti `assets/music/kkn-song.wav` dengan file musik sendiri dan ubah `musicSrc` di `script.js` bila format/nama berbeda.
6. Guestbook tersimpan di browser menggunakan localStorage.

Catatan: peta dan Google Fonts memerlukan koneksi internet; bagian utama website tetap dapat dibuka secara lokal.
